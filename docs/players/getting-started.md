# Getting started

This page is for players. It covers the first start, the folders the launcher reads, and the
keys of a controller, a keyboard and a mouse. To install the launcher, see the
[README](../../README.md#install).

The player pages show the Default theme. The Classic theme lays out Home and the Library in
another way, but its keys and its other screens are the same.

## The first start

The launcher opens full screen. On the first start, a Welcome screen lists what the launcher
sets up: your game folders, each emulator, the official art and details, and the covers. When
the list is ready, press ✕ (Enter) on **Start**.

At each start, the launcher installs the newest build of each emulator that is turned on and
has no build yet, and the boot screen waits for it. On the first start that download is a few
hundred MB. To install each emulator on its first play instead, turn off Settings → Updates →
**Install emulators automatically**.

## Where your games come from

The launcher looks for games in `~/Games` and for packages to install in `~/Downloads`. To
change the folders, go to Settings → Games. Separate several folders with `;`.

A game reaches your Library in one of these ways:

- It is in a game folder already. Each console has its own folder inside the game folder:
  `PS5`, `PS4`, `Switch` and `PC`. See [Adding a PC game by hand](downloads.md#adding-a-pc-game-by-hand).
- You install it from a package or a disc image in a packages folder, from the emulator's page.
  See [Emulators](emulators.md).
- You download it from the Catalog, and the launcher installs it. See
  [Downloads and installs](downloads.md).
- Steam installed it. See [Emulators](emulators.md#steam).

## Keys

Every screen works with a controller, a keyboard or a mouse. The table names the PlayStation
buttons. On an Xbox controller, ✕ is A and ○ is B.

| Controller | Keyboard | What it does |
| --- | --- | --- |
| D-pad, left stick | Arrow keys | Move |
| ✕ (Cross) | Enter | Select |
| ○ (Circle) | Escape or Backspace | Back |
| △ (Triangle) | `/` | Search. On the Catalog it searches the Catalog, elsewhere the Library. |
| □ (Square) | T or Insert | Play the shown game's trailer |
| Options | Menu | Open the shown game's menu. On Home, open the focused system's emulator page. |
| L1, R1 | Shift+Tab, Tab | See below |
| L2, R2 | Page Up, Page Down | Move a page up or down |
| Create (Share, View) | Delete | Close the newest notice |
| PS (Guide), tap | | Go to Home. It does nothing while a game runs. |
| PS (Guide), hold | | Close the running game. With no game running, open the power menu. |
| | Ctrl+P | Open the power menu |
| | Ctrl+D | Open Downloads |
| | Ctrl+Q | Quit the launcher |

L1 and R1 do one of three things:

- On Home and in the Library: move along the top bar, round the ends. ✕ opens the item.
- In Settings, and on a page with two sections or more: jump to the section before or after.
- On other screens: go to the screen before or after, in the order Catalog, Downloads,
  Emulators, Themes, Settings, then back to Home.

A hold of the PS button is 600 ms. A held ✕ does not repeat, so it never starts, downloads or
installs a second time.

While a game is in front, the controller belongs to the game. The launcher reads the controller
only while its own window has the focus. The PS button is the exception: it always reaches the
launcher.

With a mouse, click an item to open it. The mouse wheel scrolls.

### Typing with a controller

A text field opens an on-screen keyboard when you reach it with the controller. A physical
keyboard types into the field, and the on-screen keyboard stays shut.

| Controller | What it does |
| --- | --- |
| D-pad | Move between keys. In a search, Up from the numbers row reaches the row of matches or last searches. |
| ✕ | Type the key |
| □ | Delete |
| △ | Space |
| L1 | Shift, for one letter |
| R1 | Symbols |
| R2 or Options | Done |
| ○ | Close and keep the text |
