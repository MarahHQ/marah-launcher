# Playing

This page is for players. It covers how to start a game, close it, and tell other players how
it runs.

## Start a game

Press **Play** on the Game Hub.

If the game's emulator has no build yet, the launcher asks "Install <emulator>?". Choose
**Install and play** to install it and start the game. This happens when
**Install emulators automatically** is off, or when you press Play before the start's install
is done. See [Settings](settings.md#updates).

A splash shows while the game starts. Without a controller, the splash lists the emulator's
keyboard keys.

While a game runs, the controller belongs to the game. The top bar and the Game Hub show
**Resume** and **Stop**.

## Close a game

Close a running game in one of these ways:

- Hold the PS button.
- Choose **Stop** in the top bar or on the Game Hub.

Stop asks the game to close, and ends it when it doesn't close.

When the game closes, the launcher comes back to the front. Settings → Launcher → **Back to the
launcher** turns this off.

## Rate how a game runs

After a game closes, the launcher may ask "How far did <game> get?". It asks once for each
emulator build. To give another result, choose **Rate how it runs** in the game's menu.

Your result stays on this PC until you send it. The launcher uses it to pick the
[best version](finding-games.md#best-for-this-pc) of a game in the Catalog.

## Send your ratings

Settings → Games → **Send ratings** sends your results to the community compatibility lists, so
other players know how a game runs. Two lists take reports this way: shadPS4's (PS4 games) and
KytyPS5's (PS5 games). Results for other emulators, and for PC games, stay on this PC.

1. The launcher lists the results you haven't sent. All are picked. Press ✕ on one to leave it
   out, then choose **Next: see the reports**.
2. The launcher shows each report in full: its title, every field, the end of the emulator's
   log, and the page it goes to. Move up and down to read all of it.
3. Choose **Open in browser** to open the list's report form, filled in with that text, or
   **Skip** to send nothing. ○ (Escape) closes it, and nothing more is sent.
4. Submit the report on the page that opened. You need a free GitHub account for it. The
   launcher holds no account and sends nothing itself.

Before the report shows, the launcher takes personal data out of the log: your home folder
becomes `~`, your user name `<user>`, your computer's name `<computer>`, IP addresses `<ip>`
and email addresses `<email>`. Check the text before you submit it.

A result you opened in the browser counts as sent and isn't listed again. A new result for the
same game is listed again. shadPS4's form has a checklist that you tick yourself: shadPS4 takes
reports only for a game dumped from a copy you own, unmodified, on a major release of shadPS4.
